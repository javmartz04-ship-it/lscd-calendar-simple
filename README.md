# LSCD Class Calendar — Simple

Simplified companion to the full LSCD calendar. Same real class and event
data, lighter presentation:

- Opens directly on a full week-at-a-glance grid — no filter chips.
- A single-day lookup ("Browse By Day") sits below it for anyone who wants
  just Tuesday's classes.
- The School Year tab is one month calendar, no extra view toggle.

Live: https://javmartz04-ship-it.github.io/lscd-calendar-simple/

Compare against the full version:
https://javmartz04-ship-it.github.io/lscd-calendar/ (untouched, separate repo).

All schedule and event data lives in an editable block at the top of
`index.html` — see the comment there for how to update it. Full notes in
NOTES.md.
